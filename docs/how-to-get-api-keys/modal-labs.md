## 🇺🇸 Modal Labs Setup Guide

* **Official Platform:** [https://modal.com/](https://modal.com/)
* **Credit Card Required for Full Free Tier?** 🟠 **YES** (Card required to unlock the full \$30/month grant; without card it is limited to \$5 once).
* **Free Quota Highlights:**
  * **$30 USD / Month in Free Serverless Compute Credits:** Renews monthly on the Starter plan.
  * **GPU & Container Flexibility:** Run vLLM, Ollama, Whisper, Stable Diffusion, or custom PyTorch code on cloud GPUs (T4, L4, A10G, A100, H100).
  * **Auto-Scale to Zero:** Instances shut down within seconds when idle so your \$30 free credits can cover hundreds of inference hours for lightweight tasks.

### Step-by-Step Instructions:
1. Visit [https://modal.com/](https://modal.com/) and register with GitHub.
2. Install the Modal CLI on your machine:
   ```bash
   pip install modal
   modal setup
   ```
3. Add a payment card under **Settings > Billing** to unlock the recurring \$30/month credit tier.
4. Deploy any serverless LLM or function using Modal's Python decorators.
