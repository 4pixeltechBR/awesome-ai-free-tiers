## 💡 Why This Directory Exists
Most "free AI API" lists on the web suffer from three fatal flaws:
1. **Outdated Limits:** Lists claim a model is free when the provider quietly shut off quotas months ago.
2. **Hidden Paywalls & Affiliate Traps:** Promoted links redirect to paid proxy wrappers or spam referrals.
3. **Internal Routing Confusion:** Listing internal engine cluster IDs rather than canonical API payload IDs, causing developer code to crash.

This repository fixes that with **strict runtime auditing, zero affiliate links, and verifiable test snippets**.

## 💡 Por que este repositório existe?
A maioria dos tutoriais de IA na internet engana o desenvolvedor com três problemas graves:
1. **Limites e Cotas Obsoletos:** Artigos indicam modelos que deixaram de ser gratuitos há meses.
2. **Pegadinhas de Cobrança e Afiliados:** Links mascarados que exigem cartão ou redirecionam para serviços pagos.
3. **Nomes Incorretos de Modelos:** Publicar nomes de marketing que quebram a requisição da API por não serem os IDs canônicos.

Nosso compromisso é com a **verdade técnica, transparência total e zero links de afiliados**.
